# blaueis-gateway

WebSocket-to-UART bridge that runs on a Raspberry Pi (or similar) and exposes
one or more Midea AC units over WebSocket to
[blaueis-client](https://pypi.org/project/blaueis-client/) consumers.

## Install

```sh
pip install blaueis-gateway
```

Provides the `blaueis-configure` CLI for first-time setup.

## Documentation

Part of the [blaueis-libmidea](https://github.com/fabcoded/blaueis-libmidea)
project. See the [repo docs](https://github.com/fabcoded/blaueis-libmidea/tree/main/docs)
for deployment and operations details.
