# blaueis-core

Midea HVAC serial-protocol library — codec, glossary, state, query, and
command construction for Midea AC units.

## Install

```sh
pip install blaueis-core
```

## Documentation

Part of the [blaueis-libmidea](https://github.com/fabcoded/blaueis-libmidea)
project. See the [repo docs](https://github.com/fabcoded/blaueis-libmidea/tree/main/docs)
for architecture, protocol, and versioning details.
