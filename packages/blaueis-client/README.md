# blaueis-client

Async WebSocket client and Device wrapper for talking to a
[blaueis-gateway](https://pypi.org/project/blaueis-gateway/) instance.

## Install

```sh
pip install blaueis-client
```

## Documentation

Part of the [blaueis-libmidea](https://github.com/fabcoded/blaueis-libmidea)
project. See the [repo docs](https://github.com/fabcoded/blaueis-libmidea/tree/main/docs)
for the WebSocket protocol and architecture details.
